# wave_loop_detector
waveファイル専用ループ部分検出・編集プログラム

## 概要
waveファイルに対し，高速フーリエ変換を実施し，数学的厳密さによって音楽のループ部分を検出，編集するプログラムです．
ループ部分を検知し，指定した時間(分)に達するまでループ部分をシームレスに足し合わせたロングバージョンのwaveファイルを出力します．
イントロ部分，ループ部分の単体抽出も可能です．
フェードアウト処理の実行も可能です．

* windows専用．
* ランタイム不要．

## 対応ファイル
用途に応じて，2つの実行ファイルを使い分けてください．

### 1. 'BGMExtender_short.exe'
**曲の2回目のループ部分が4秒以上含まれているかつ，ファイル末尾で途切れているwaveファイル専用**です。
* 2回目のループが最後まで完全に入っている場合は，BGMExtender_long.exeを使ってください．
* ファイル末尾の2回目のループ部に，4秒以上フェードアウト処理が施されていない箇所がある場合は，検知できます．

### 2. 'BGMExtender_long.exe'
**ループ部分が完全に2回(もしくはそれ以上)含まれているwaveファイル専用**です．

## 使い方
### 【事前準備】
出力されたファイルは `music_output` フォルダに保存されます。
実行する前に、**必ずexeファイルと同じディレクトリ内に `music_output` という名前の空フォルダを作成**してください。

### 【実行方法】
対応する実行プログラム（.exe）をダウンロードし、以下のいずれかの方法で実行します。
1. 処理したい音楽ファイル（.wav）を exeファイルに直接 **ドラッグ&ドロップ** する。
2. コマンドプロンプト等から、コマンドライン引数にwaveファイルの相対パスを渡して実行する。
