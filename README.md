# wave_loop_detector
waveファイル専用ループ部分検出・編集プログラム

## 概要
waveファイルに対し，高速フーリエ変換を実施し，数学的厳密さによって，音楽のループ部分を検出，編集するプログラム．
ループ部分を検知し，指定した時間(分)に達するまでループ部分を足し合わせたファイルを出力します．
イントロ抽出，ループ部分抽出，アウトロ抽出も可能です．
windows専用です．
ランタイム不要です．

## 対応ファイル
### **BGMExtender_short.exe**
対応しているwaveファイルは，曲のループ部分の2回目が**4秒**以上あるファイル．
2回目のループの全体が入っている場合は，BGMExtender_long.exeを使ってください．
ファイル末の2回目のループ部に，4秒以上フェードアウト処理が施されていない部分がある場合は，検知できます．
### **BGMExtender_long.exe**
対応しているファイルは，ループ部分が完全に2回，もしくはそれ以上含まれているwaveファイル．

## 使い方
対応する実行プログラム**exe**をダウンロードして，音楽ファイルをドラッグ&ドロップ，または実行コマンドでコマンドライン引数に相対パスを渡すことで使えます．
出力は**music_output**フォルダにされるので，実行ファイルと同じディレクトリ内に，**music_output**フォルダの生成を行ってください．
